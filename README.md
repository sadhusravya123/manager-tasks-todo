

## Manager Task Assignment

## Aim
To develop a React application for assigning tasks to team members.

## Technologies Used
- React
- JavaScript
- HTML
- CSS

## Description
The Manager Task Assignment application allows a manager to assign tasks to team members and display the assigned tasks.

## Features
- Add task details
- Assign tasks to team members
- Display assigned tasks
- Manage task information
- Dynamic UI using React

## How to Run
```bash
npm install
npm start
